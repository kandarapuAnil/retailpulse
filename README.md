## 📌 Project Overview

RetailPulse is an end-to-end Retail Analytics and Demand Forecasting platform developed using Python, Streamlit, and Machine Learning.

The platform enables retail businesses to analyze sales performance, forecast future demand, segment customers, predict customer churn, and optimize inventory decisions through an interactive business intelligence dashboard.

This project demonstrates the complete Data Science lifecycle including:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Machine Learning
- Forecasting
- Business Intelligence Dashboard
- Explainable AI (SHAP)

---

# 🎯 Business Problem

Retail organizations generate massive volumes of transactional data but often struggle to transform it into actionable insights.

Common challenges include:

- Poor demand forecasting
- Customer churn
- Overstocking and stockouts
- Low customer retention
- Limited business intelligence

RetailPulse addresses these problems using predictive analytics and machine learning to support data-driven decision-making.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/anilkandarapu/RetailPulse.git
```

## Navigate to Project

```bash
cd RetailPulse
```

## Create Virtual Environment

```bash
python -m venv .venv
```

## Activate Environment

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app/app.py
```
